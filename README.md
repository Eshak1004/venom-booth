## Projects

### Free Trading Backtester

A Python and Streamlit research app for backtesting a simple moving-average strategy using public Binance crypto candles, Yahoo Finance data where available, or a user-provided OHLCV CSV file.

- [Open the project folder](./free-trading-backtester/)
- [Read setup and usage instructions](./free-trading-backtester/README.md)
- Features: historical backtesting, periodically refreshed market data, equity curve, performance metrics, and CSV downloads.

**Important:** Free data can be delayed or limited. This is an educational backtesting prototype, not a trading execution platform or financial advice.
